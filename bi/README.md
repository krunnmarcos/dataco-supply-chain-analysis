# Power BI

Power BI project (PBIP: TMDL semantic model + PBIR report) for the DataCo analysis.

## Data source

Star schema parquet files generated by the ETL:

```bash
cd src && ../.venv/bin/python -m dataco.transform   # writes data/processed/star/*.parquet
```

The folder is the Power Query parameter `PastaDados` (Transform data > Manage parameters). Change it if the repo lives elsewhere on your machine.

## Model (star schema)

| Table | Grain / content |
| --- | --- |
| `fVendas` | fact, one row per order item: keys, dates, delivery days, late flag, quantity, revenue, profit |
| `dCategoria` | category and department |
| `dProduto` | product and price |
| `dCliente` | customer, segment and location |
| `dLocalSaida` | origin (store) city/state with average latitude/longitude |
| `dLocalEntrega` | delivery city/state/country, region and market |
| `dTipoEntrega` | shipping mode and scheduled days |
| `Calendario` | DAX date table (marked as date table), related to `fVendas[Data Pedido]` |
| `_Medidas` | all measures, in display folders: Vendas, Lucro, Entregas, Clientes |

Delivery-rate measures count orders (`Pedido Id`), not items.

## Report pages

1. **Atrasos por Localização** — late-delivery KPIs, origin and delivery maps (red = most critical), most affected cities, late rate by market and shipping mode.
2. **Vendas por Categoria** — revenue, best-selling and loss-making products, monthly purchases, categories most affected by delays, top customers.
3. **Produtos** — searchable product slicer, Pareto, delivery map, revenue x margin, monthly revenue and product detail.

Year, shipping mode and market slicers are synced across pages.
